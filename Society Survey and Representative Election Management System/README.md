# 🏘️ Society Survey and Representative Election Management System

A responsive web application developed using **HTML5 and CSS3** to facilitate **society surveys, resident participation, and representative elections** within a residential community. The system enables residents to register, participate in surveys, vote for representatives, view election results, and stay informed about community activities.

---

## 📌 Project Overview

The **Society Survey and Representative Election Management System** is designed to improve communication and decision-making within residential societies. The platform provides a centralized system where residents can:

- Register and manage their participation.
- Submit feedback through surveys.
- Vote for society representatives.
- View candidate information and election results.
- Access announcements and election schedules.

This project demonstrates the implementation of responsive web design principles using pure HTML and CSS.

---

## ✨ Features

### 🏠 Home Page
- Introduction to the Society Survey and Election System.
- Overview of the election process.
- Quick access buttons for:
  - Registration
  - Login
  - Active Polls

### 👤 Resident Registration
Residents can create an account by providing:
- Full Name
- Flat/House Number
- Email Address
- Mobile Number
- Password Confirmation
- Resident Type (Owner/Tenant)

### 🔐 Login System
- Secure login form for registered residents.
- Redirects users to the dashboard after authentication.

### 📊 Resident Dashboard
Provides an overview of:
- Active Surveys
- Ongoing Elections
- Candidate Information
- Election Results

Additional features:
- Recent announcements
- Election timeline and schedule

### 📝 Society Survey Module
Residents can provide feedback regarding:

- Cleanliness Satisfaction
- Security Services
- Parking Management Issues
- Water Supply Quality
- Maintenance Services
- General Suggestions

### 🗳️ Poll Management
Displays active elections including:
- President Election
- Secretary Election
- Treasurer Election
- Cultural Committee Head Election
- Security Coordinator Election

Each poll contains:
- Election description
- Voting period
- Current status
- Direct voting access

### 👥 Candidate Management
Residents can view candidate profiles including:

- Candidate Name
- Position Applied For
- Experience
- Manifesto
- Society Contributions
- Contact Information

### ✅ Voting System
Allows residents to:
- Review candidate details.
- Cast votes for preferred representatives.
- Participate in transparent election processes.

### 📈 Election Results
Displays:
- Winning candidate information.
- Votes received by each candidate.
- Vote percentage distribution.
- Graphical representation using progress bars.

### 📞 Contact and Support
Provides:
- Contact form for resident queries.
- Society office address.
- Official email address.
- Phone number.
- Office working hours.
